# typesafe-public-examples

Content used as part of documentation, demos, and cookbooks.

## Licensing

Code and TypeSafe's own data are under the [MIT licence](LICENSE).

Some folders under `cookbooks/` and `integrations/` also hold third-party data, which keeps its own licence. Each such folder has a `DATA_LICENSE.md` that names the source, its licence, and any changes we made. Licence texts that must travel with the data are in [`LICENSES/`](LICENSES).
