# Data licence

`filings.jsonl` holds excerpts from 10-K annual reports filed with the U.S. Securities and Exchange Commission, from [EDGAR](https://www.sec.gov/edgar).

`sic_codes.tsv` is the SEC's [SIC code list](https://www.sec.gov/corpfin/division-of-corporation-finance-standard-industrial-classification-sic-code-list), a U.S. government work in the public domain.

The other files this cookbook publishes to typesafe-public-examples are TypeSafe's work under that repository's MIT licence.
