# Data licence

`hermes_roster.json` is built from the skills in [NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent) at commit [`6bb377a51d5c8e279a7a5e34d717d653d421d064`](https://github.com/NousResearch/hermes-agent/tree/6bb377a51d5c8e279a7a5e34d717d653d421d064). Each record holds a skill's name, category and description, the description clipped to 60 characters as the Hermes skill index shows it, and the first 1600 characters of the skill's `SKILL.md` body with whitespace collapsed.
